# RL Grasping & Manipulation. NVIDIA Isaac Lab

Обучение робота-манипулятора Franka захвату, подъёму и перемещению объектов с использованием Reinforcement Learning.

Технологии: Python, NVIDIA Isaac Lab, RSL-RL.

## 1. Постановка задачи

Цель проекта — обучить манипулятор Franka захватывать куб со стола, поднимать его и перемещать в случайно заданную целевую позицию.

В качестве основы использовалась готовая симуляционная среда Isaac Lab, адаптированная под задачу. Для обучения политики применялся RSL-RL.

Дополнительно исследовалось способность обученной политики работать с объектами другой геометрии без дообучения.

## 2. Reward hacking

На первых этапах обучения столкнулся с проблемой **reward hacking** — агент научился получать награду, не выполняя поставленную задачу.
Изначально функция награды за подъём куба срабатывала даже тогда, когда куб не находился в схвате манипулятора. В результате агент вместо захвата научился «пинать» куб таким образом, чтобы тот оказывался ровно на краю стола. Таким образом, агент фактически нашёл компромисс между двумя составляющими функции награды: достаточно сильный толчок позволял получить вознаграждение за увеличение высоты куба, но при этом необходимо было избежать его падения со стола, за которое предусматривался огромный штраф.

Увеличение продолжительности обучения не устранило проблему: агент продолжал использовать найденную стратегию.

**Решение:** добавил дополнительное условие для получения награды за подъём — куб должен находиться в непосредственной близости от схвата манипулятора. После этого агент перестал использовать прежнюю стратегию и начал осваивать корректный захват и подъём объекта.

## 3. Результаты обучения

После корректировки функции награды удалось обучить политику, выполняющую последовательность действий:

1. Приближение схвата к кубу.
2. Захват объекта.
3. Подъём над поверхностью стола.
4. Перемещение объекта к случайно заданной целевой позиции.

###  Анализ метрик

Для анализа обучения использовался TensorBoard с отслеживанием отдельных компонентов функции награды.

**Reaching Object**

Награда за приближение схвата к объекту увеличивается и постепенно стабилизируется. Это согласуется с освоением агентом необходимого позиционирования манипулятора относительно куба.

**Lifting Object**

После начального роста награда за подъём объекта выходит на плато. Это указывает на стабилизацию соответствующей компоненты обучения. Визуальная проверка в симуляции подтверждает выполнение подъёма куба.

**Object Goal Tracking**

Награда за перемещение объекта к целевой позиции постепенно растёт и стабилизируется. Это согласуется с освоением агентом перемещения удерживаемого объекта к заданной цели.

**Action Rate и Joint Velocity**

В процессе обучения использовалось постепенное усиление штрафов, связанных с изменением управляющих воздействий и скоростями суставов.
Это позволило сначала дать агенту больше свободы для исследования возможных действий, а затем усилить требования к плавности движений.

**Object Velocity**

Штраф за скорость объекта продолжал изменяться на поздних этапах обучения. Это может указывать на сохраняющиеся изменения в динамике перемещения объекта.

## 4. Эксперимент с другими объектами

После успешного обучения на кубе решил проверить, насколько полученная политика переносится на объекты другой геометрии. Для тестирования использовались цилиндрические объекты, банки и коробки, сопоставимые по размерам с исходным кубом. Политика, обученная только на кубе, в отдельных случаях могла захватывать другие объекты, однако качество выполнения задачи снижалось. Возможно дообучение политики для повышения успешности выполнения задачи.

## 5. Итоги

В ходе проекта удалось:

- Обучить RL-политику захвату, подъёму и переносу куба.

- Выявить и устранить reward hacking путём изменения условий начисления награды за подъём объекта.

- Исследовать влияние настройки вознаграждений и штрафов на поведение агента.

- Применить постепенное усиление штрафов для регулирования плавности движений.

- Проверить переносимость обученной политики на объекты другой геометрии и выявить её ограничения.
